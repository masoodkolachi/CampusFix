# CampusFix

Campus Problem Reporting System for the Web Engineering course.

Stack: React (Vite), Node.js, Express, MongoDB, JWT.

## Run locally

Server:

    cd server
    copy .env.example .env
    npm install
    npm run seed:admin
    npm run dev

Client:

    cd client
    copy .env.example .env
    npm install
    npm run dev

Server runs on http://localhost:5000 and the client on http://localhost:5173.
